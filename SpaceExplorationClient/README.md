# 🌍 Cosmo Trails - Frontend Web Application

Modern Spring MVC web application with server-side rendering, providing an intuitive interface for space mission management.
![Image](https://github.com/user-attachments/assets/a37b5410-eb4c-4bb4-abe8-a44215db0bb4)

🎯 Project Overview

Server-side rendered web application that consumes the Cosmo Trails REST API, providing users with an engaging interface to manage space missions, recruit astronauts, and track their exploration budget.

## 🛠️ Technology Stack

### Core Framework

Spring Boot - Application framework

Spring MVC - Web layer and routing

Spring Security - Session-based authentication

Thymeleaf - Server-side template engine

### Frontend Technologies

Bootstrap - Responsive UI framework

JavaScript - Enhanced interactivity

HTML - Modern web standards

Custom CSS - Space-themed styling

Three.js — Interactive 3D Space Map

### Integration

RestTemplate - REST API communication

Jackson - JSON serialization/deserialization

Maven - Build and dependency management


## Mission Management

Create Mission Flow:

1. Select destination from gallery

2. Define mission parameters

3. Add astronauts based on specializations

4. Review success probability

5. Confirm and launch

6. Save mission report
